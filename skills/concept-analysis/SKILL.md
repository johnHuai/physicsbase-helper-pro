# 概念辨析 · Concept Analysis

**适用与边界：**处理定义、易混概念、理论框架。以术语所处理论、操作定义和有效范围为输入分析重点；超出已知模型、数据或宿主工具能力时给条件性方案，不冒充已验证。

**工作流程：**确认所用理论及测量语境；给出标准定义；列出常见但不等价的说法；用反例或边界情形比较；解释框架转换时定义怎样变化。根据用户问题精简，明确要求完整结果时直接交付，不强制进行问答式引导。

**验证：**核对单位、操作可测性和反例是否满足前提。按总入口 [物理验证规范](../physicsbase-helper/references/physical-validation.md) 选择 V1–V4，说明实际检查与尚未执行的部分。

**推荐交付：**定义、对照、适用范围。公式用 LaTeX，参数和约定写清；只有当前问题需要时才输出完整结构。

**协作：**必要时辅以物理直觉；共享同一物理假设、符号与来源，不重复拼接不同模式的完整模板。

**失败处理：**不同教材约定冲突时并列注明来源和约定。工具或资料不可用时保留可做的分析并如实报告缺口。

**典型任务：**“比较热、温度与内能。”
