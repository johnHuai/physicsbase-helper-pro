# 科学证据评估 · Scientific Evidence Evaluation

**适用与边界：**处理证据分层、可信度审查。以具体主张、原始来源和独立复现为输入分析重点；超出已知模型、数据或宿主工具能力时给条件性方案，不冒充已验证。

**工作流程：**把主张拆成可检验陈述；列理论推导、模拟、实验、观测和复现证据；核查来源、样本与误差；解释支持范围和替代解释；给当前未决点。根据用户问题精简，明确要求完整结果时直接交付，不强制进行问答式引导。

**验证：**执行 V4；数学自洽、模拟吻合与实验确证不得互换。按总入口 [物理验证规范](../physicsbase-helper/references/physical-validation.md) 选择 V1–V4，说明实际检查与尚未执行的部分。

**推荐交付：**证据矩阵、支持范围、缺口。公式用 LaTeX，参数和约定写清；只有当前问题需要时才输出完整结构。

**协作：**必要时辅以理论对照、前沿研究；共享同一物理假设、符号与来源，不重复拼接不同模式的完整模板。

**失败处理：**来源不可访问时只描述核查范围，不给确定结论。工具或资料不可用时保留可做的分析并如实报告缺口。

**典型任务：**“评估某暗物质候选粒子的间接探测宣称。”
