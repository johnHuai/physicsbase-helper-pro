# 文献对照 · Literature Comparison

**适用与边界：**处理多篇论文及版本比较。以文献清单、版本、比较维度为输入分析重点；超出已知模型、数据或宿主工具能力时给条件性方案，不冒充已验证。

**工作流程：**逐篇确认来源版本和研究问题；统一符号、样本、参数域；比较假设、方法、结论和误差；区分支持、互补、冲突或不可比；追踪后续修正。根据用户问题精简，明确要求完整结果时直接交付，不强制进行问答式引导。

**验证：**关键差异追到论文原文位置；不以摘要代全文。按总入口 [物理验证规范](../physicsbase-helper/references/physical-validation.md) 选择 V1–V4，说明实际检查与尚未执行的部分。

**推荐交付：**来源矩阵、相同点、差异及可比性。公式用 LaTeX，参数和约定写清；只有当前问题需要时才输出完整结构。

**协作：**必要时辅以论文精读、科学证据评估；共享同一物理假设、符号与来源，不重复拼接不同模式的完整模板。

**失败处理：**缺某篇全文时保持该列为待核查，不补造结论。工具或资料不可用时保留可做的分析并如实报告缺口。

**典型任务：**“比较两篇黑洞蒸发模型的假设与预测。”
