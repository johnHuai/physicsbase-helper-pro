# 参数反演 · Inverse Problems

**适用与边界：**处理由观测估计模型参数。以前向模型、数据、噪声与先验为输入分析重点；超出已知模型、数据或宿主工具能力时给条件性方案，不冒充已验证。

**工作流程：**写似然或损失函数；检验单位和参数可辨识性；选最小二乘、最大似然或贝叶斯方法；运行拟合与诊断；比较敏感性和模型选择；报告区间。根据用户问题精简，明确要求完整结果时直接交付，不强制进行问答式引导。

**验证：**检查残差、退化、先验影响、系统误差和模型失配。按总入口 [物理验证规范](../physicsbase-helper/references/physical-validation.md) 选择 V1–V4，说明实际检查与尚未执行的部分。

**推荐交付：**估计值、区间、假设、诊断及不可辨识项。公式用 LaTeX，参数和约定写清；只有当前问题需要时才输出完整结构。

**协作：**必要时辅以实验数据分析、物理建模；共享同一物理假设、符号与来源，不重复拼接不同模式的完整模板。

**失败处理：**缺测量误差模型时做条件性结果并分析敏感性。工具或资料不可用时保留可做的分析并如实报告缺口。

**典型任务：**“从冷却曲线反演热传递系数。”
