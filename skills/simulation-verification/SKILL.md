# 仿真验证 · Simulation Verification

**适用与边界：**处理数值结果审计、收敛和复现。以代码、数据、算法、参数与预期物理约束为输入分析重点；超出已知模型、数据或宿主工具能力时给条件性方案，不冒充已验证。

**工作流程：**复现运行条件；构造解析或高精度基准；改变步长/网格/精度；测残差与守恒；检验稳定和边界处理；随机实验重复并估计误差。根据用户问题精简，明确要求完整结果时直接交付，不强制进行问答式引导。

**验证：**标出实际完成的测试及其覆盖域；单次结果不能称收敛。按总入口 [物理验证规范](../physicsbase-helper/references/physical-validation.md) 选择 V1–V4，说明实际检查与尚未执行的部分。

**推荐交付：**测试矩阵、误差阶、失败点、可靠范围。公式用 LaTeX，参数和约定写清；只有当前问题需要时才输出完整结构。

**协作：**必要时辅以数值模拟、推导审查；共享同一物理假设、符号与来源，不重复拼接不同模式的完整模板。

**失败处理：**缺代码或机器时静态审查并单列未运行检查。工具或资料不可用时保留可做的分析并如实报告缺口。

**典型任务：**“审查热方程显式格式是否违反稳定性界限。”
