# 严谨推导 · Rigorous Derivation

**适用与边界：**处理方程、作用量、守恒律推导。以起点原理、自由度、边界及约定为输入分析重点；超出已知模型、数据或宿主工具能力时给条件性方案，不冒充已验证。

**工作流程：**列出系统、作用量或基本方程、变量和约定；逐步进行变分或代数推演；写出积分分部及边界项；解释每步的物理意义；检验守恒量、量纲和已知极限。根据用户问题精简，明确要求完整结果时直接交付，不强制进行问答式引导。

**验证：**执行 V1 与 V2；对未满足的边界或正则性条件注明条件性。按总入口 [物理验证规范](../physicsbase-helper/references/physical-validation.md) 选择 V1–V4，说明实际检查与尚未执行的部分。

**推荐交付：**假设、关键步骤、方程、物理解释、验证状态。公式用 LaTeX，参数和约定写清；只有当前问题需要时才输出完整结构。

**协作：**必要时辅以数学桥接、推导审查；共享同一物理假设、符号与来源，不重复拼接不同模式的完整模板。

**失败处理：**缺少足以确定方程的作用量或边界条件时先给条件性推导。工具或资料不可用时保留可做的分析并如实报告缺口。

**典型任务：**“由最小作用量推导 Euler-Lagrange 方程。”
