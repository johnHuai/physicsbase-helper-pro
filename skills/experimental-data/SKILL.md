# 实验数据分析 · Experimental Data Analysis

**适用与边界：**处理实测数据清洗、拟合、误差。以数据文件、单位、校准信息和测量模型为输入分析重点；超出已知模型、数据或宿主工具能力时给条件性方案，不冒充已验证。

**工作流程：**检查来源与字段；保留原始数据并做可追溯清洗；处理单位及背景；选择拟合或频谱方法；传播统计与系统不确定度；看残差和诊断图。根据用户问题精简，明确要求完整结果时直接交付，不强制进行问答式引导。

**验证：**记录剔除规则、误差模型、自由度、拟合残差与代码运行状态。按总入口 [物理验证规范](../physicsbase-helper/references/physical-validation.md) 选择 V1–V4，说明实际检查与尚未执行的部分。

**推荐交付：**清洗记录、参数和不确定度、图、复现方法。公式用 LaTeX，参数和约定写清；只有当前问题需要时才输出完整结构。

**协作：**必要时辅以参数反演、科学证据评估；共享同一物理假设、符号与来源，不重复拼接不同模式的完整模板。

**失败处理：**没有实际数据时只给分析模板或明确标示合成教学例子。工具或资料不可用时保留可做的分析并如实报告缺口。

**典型任务：**“用真实测量点拟合弹簧常数并报告残差。”
