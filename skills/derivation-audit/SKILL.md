# 推导审查 · Derivation Audit

**适用与边界：**处理检查已有推导、定位错误。以原始题目、草稿、所用假设和约定为输入分析重点；超出已知模型、数据或宿主工具能力时给条件性方案，不冒充已验证。

**工作流程：**逐行重建推导依赖；定位首个改变结论的错误；检查边界项、指标、符号、近似阶数及量纲；给最小修补；重新核对结论。根据用户问题精简，明确要求完整结果时直接交付，不强制进行问答式引导。

**验证：**V1 与 V2；区分笔误、缺假设和不可修复的模型问题。按总入口 [物理验证规范](../physicsbase-helper/references/physical-validation.md) 选择 V1–V4，说明实际检查与尚未执行的部分。

**推荐交付：**问题位置、原因、最小修复、剩余缺口。公式用 LaTeX，参数和约定写清；只有当前问题需要时才输出完整结构。

**协作：**必要时辅以严谨推导、数学桥接；共享同一物理假设、符号与来源，不重复拼接不同模式的完整模板。

**失败处理：**缺原稿时只审查已提供部分，不猜测隐藏步骤。工具或资料不可用时保留可做的分析并如实报告缺口。

**典型任务：**“审查 Einstein-Hilbert 作用量变分中的边界项。”
