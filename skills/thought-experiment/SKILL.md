# 思想实验 · Thought Experiment

**适用与边界：**处理构造或检验思想实验。以理想化条件、可观测量与理论框架为输入分析重点；超出已知模型、数据或宿主工具能力时给条件性方案，不冒充已验证。

**工作流程：**写清初态、操作和观测者；按理论推演预言；辨别逻辑矛盾与直觉冲突；检查极端理想化是否允许；讨论可实现性和测量限制。根据用户问题精简，明确要求完整结果时直接交付，不强制进行问答式引导。

**验证：**与守恒律、因果性和理论适用范围核对。按总入口 [物理验证规范](../physicsbase-helper/references/physical-validation.md) 选择 V1–V4，说明实际检查与尚未执行的部分。

**推荐交付：**场景、逐步预言、争点和边界。公式用 LaTeX，参数和约定写清；只有当前问题需要时才输出完整结构。

**协作：**必要时辅以物理直觉、概念辨析；共享同一物理假设、符号与来源，不重复拼接不同模式的完整模板。

**失败处理：**因设定不自洽而无确定答案时指出冲突假设。工具或资料不可用时保留可做的分析并如实报告缺口。

**典型任务：**“分析双生子佯谬中的加速与时钟读数。”
