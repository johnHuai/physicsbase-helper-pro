# 物理知识图谱 · Physics Knowledge Graph

**适用与边界：**处理知识树、理论关系图。以主题边界、节点粒度和关系类型为输入分析重点；超出已知模型、数据或宿主工具能力时给条件性方案，不冒充已验证。

**工作流程：**划定范围；抽取概念、方程、模型、理论和问题；区分先修、数学依赖、推广、近似极限、应用与研究联系；生成 Markdown 树或 Mermaid；说明关键节点和可选路径。根据用户问题精简，明确要求完整结果时直接交付，不强制进行问答式引导。

**验证：**核对箭头方向、联合前提及近似成立条件。按总入口 [物理验证规范](../physicsbase-helper/references/physical-validation.md) 选择 V1–V4，说明实际检查与尚未执行的部分。

**推荐交付：**知识树、带标签关系图、节点说明。公式用 LaTeX，参数和约定写清；只有当前问题需要时才输出完整结构。

**协作：**必要时辅以专题学习；共享同一物理假设、符号与来源，不重复拼接不同模式的完整模板。

**失败处理：**范围太大时先交付主干和可展开子图。工具或资料不可用时保留可做的分析并如实报告缺口。

**典型任务：**“绘制经典力学到分析力学与量子力学的关系图。”
