# 科研证据账本

每个重要研究条目记录：标题、作者、年份、DOI/arXiv ID 或官方标识、具体版本、获取来源、核查日期、问题、主要结论、物理假设、数学/数值方法、实验或观测支持、与其他工作的关系、限制与仍未解决的部分。缺字段标记“待核查”，不补造。

前沿研究可用下列模板保存到用户授权的项目目录；本插件自身不自动持久化研究笔记：

```text
问题与精确定义：
来源、版本、核查日期：
路线 A/B/C 及各自假设：
已证结果／数值结果／实验观测：
独立复现与冲突证据：
未解决障碍与有效范围：
下一步可检验问题：
```

优先原始论文、机构官方资料和原始数据。arXiv、INSPIRE HEP、NASA ADS、CERN、NASA/ESA、NIST、GWOSC 是按需检索来源，不是插件内置数据库。最新状态必须当次核查；未检索到不等于不存在。定时追踪只有宿主提供相应调度功能并实际配置后才能声称存在。
