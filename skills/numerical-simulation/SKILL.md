# 数值模拟 · Numerical Simulation

**适用与边界：**处理ODE、PDE、Monte Carlo、量子动力学。以模型、初边值、参数单位、精度与产物为输入分析重点；超出已知模型、数据或宿主工具能力时给条件性方案，不冒充已验证。

**工作流程：**选择适合方程和守恒结构的算法；检查实际环境；实现并记录依赖、步长、网格、种子；运行基准和目标情形；计算误差、守恒与收敛；交付代码、图和复现命令。根据用户问题精简，明确要求完整结果时直接交付，不强制进行问答式引导。

**验证：**V2 与 V3；有限分辨率结果不推出连续模型普遍规律。按总入口 [物理验证规范](../physicsbase-helper/references/physical-validation.md) 选择 V1–V4，说明实际检查与尚未执行的部分。

**推荐交付：**代码、实际结果、误差、环境、复现步骤。公式用 LaTeX，参数和约定写清；只有当前问题需要时才输出完整结构。

**协作：**必要时辅以物理建模、仿真验证、物理可视化；共享同一物理假设、符号与来源，不重复拼接不同模式的完整模板。

**失败处理：**无法执行时仅交付方案，报告依赖和未验证状态。工具或资料不可用时保留可做的分析并如实报告缺口。

**典型任务：**“模拟单摆并比较不同时间步的能量漂移。”
