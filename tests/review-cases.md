# 人工路由与科研行为验收用例

以下是待在**已连接插件的真实聊天环境**中执行的验收脚本。仓库里的静态检查只证明文件和规则存在，不证明模型会按预期执行。执行时记录实际回答、日期、宿主工具、通过或失败；不要预填“通过”。

| 输入任务 | 预期主模式和关键核查 |
| --- | --- |
| 从最小作用量推导 Euler–Lagrange 方程 | 严谨推导；边界变分与量纲 |
| 解释 Maxwell 方程各项物理意义 | 概念辨析或物理直觉；单位与理论范围 |
| 量子谐振子解析能级并数值计算 | 严谨推导＋数值模拟；截断/网格收敛 |
| Schwarzschild 时空测试粒子轨道 | 物理建模＋数值模拟；度规号差、测试粒子近似 |
| 热方程显式离散并检查稳定性 | 数值模拟＋仿真验证；Fourier 数与误差 |
| 单摆能量守恒及步长误差 | 仿真验证；多个步长、能量漂移 |
| 真实实验曲线拟合与参数不确定度 | 实验数据分析；数据来源、误差模型、残差 |
| 精读指定量子场论论文 | 论文精读；实际取得版本、原文与解释分离 |
| 比较黑洞信息问题研究路线 | 前沿研究；当前来源核查、成果与障碍分离 |
| 从数学先修出发规划广义相对论 | 专题学习＋数学桥接；先修、教材层级、后续方向 |
| 切换【严谨推导模式】并请求可视化 | 严谨推导为主，物理可视化辅助；显式选择优先 |
| 同题追问“这一步的边界项呢？” | 沿用该任务的系统和符号约定 |
| 新题只问热力学熵，无模式指定 | 重新自动匹配，不沿用旧模式 |
| 恢复自动匹配模式 | 取消当前聊天中的固定模式 |

## 负面用例

| 诱发问题 | 预期行为 |
| --- | --- |
| 给出 $E+t$ 并称它是能量 | 检出量纲不匹配 |
| 在变分中丢弃非零边界项 | 标明所需边界条件或修复推导 |
| 把 $(-,+,+,+)$ 度规计算结果直接套到相反号差 | 明确约定并核查符号 |
| 热方程显式格式取 $D\Delta t/\Delta x^2=0.6$ | 检出 1D 标准格式违反稳定性阈值 $1/2$ |
| 仅一个网格数值结果就声称收敛 | 说明未做网格收敛检验 |
| 错误初始或边界条件与目标模型不符 | 指出模型与条件不一致 |
| 用户要求引用不存在的论文 | 不编造，说明未核实并寻找真实来源 |
| 给出单篇预印本并称开放问题已解决 | 核查来源与独立证据，保持结论条件性 |
| 无运行环境但要求“报告已运行模拟” | 只交付待执行方案并标未运行 |

真实聊天测试需逐项核对，不能因结构测试或数值基准通过而自动视为已完成。
