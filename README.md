# PhysicsBaseHelper-Pro

PhysicsBaseHelper-Pro 是一个独立的物理学习与科研 Skills 插件。它覆盖从本科基础物理到现代物理研究的 24 种工作模式，按任务成果自动选择，用户明确指定时优先。v1.0.0 为技能型插件：它提供工作流程和核查规范，不内置计算服务器、数据库或持续监控服务。

## 启用

在 Codex / ChatGPT 的插件页面打开私有插件链接并启用；也可从本仓库的完整 ZIP 包安装到支持 Agent Plugins 1.0 的客户端。首次输入“启用 PhysicsBaseHelper-Pro，介绍全部可用模式”，以后直接提问即可。公共 GitHub 仓库只公开源代码；账号内插件的可见性是独立设置。

模式操作：

- 自动选择：“从最小作用量推导 Euler-Lagrange 方程，并检查边界项。”
- 显式选择：“切换【严谨推导模式】，推导 Maxwell 方程的波动形式。”
- 混合任务：“模拟单摆并画能量漂移曲线”，以数值模拟为主，辅助仿真验证和可视化。
- 取消固定：“恢复自动匹配模式”。仅在用户明确要求固定时，才在当前聊天维持模式。

插件不会替用户自动安装依赖或假装某个计算已经运行。要实际运行模拟，请给出方程、参数、初边值、单位和期望产物；它会检查宿主工具，再选择可用后端。缺工具时会交付代码和复现方法，并写明未运行。文献任务最好提供论文链接、DOI/arXiv ID 或原文；最新进展须使用实际可访问的来源核查。

## 24 种模式

| 体系 | 模式 | 常见成果 |
| --- | --- | --- |
| 基础物理与理论学习 | 物理直觉、概念辨析、严谨推导、习题训练 | 图像解释、定义比较、方程推导、习题解答 |
| 系统学习与数学桥接 | 专题学习、物理知识图谱、数学桥接、推导审查 | 学习路径、关系图、数学先修、错误定位 |
| 理论建模与研究 | 物理建模、近似与有效理论、理论对照、思想实验 | 控制方程、受控近似、理论比较、思想实验分析 |
| 科学计算与可视化 | 符号与张量计算、数值模拟、仿真验证、物理可视化 | 符号式、可复现代码、误差报告、图像动画 |
| 实验与观测研究 | 实验设计、实验数据分析、参数反演、科学证据评估 | 实验方案、拟合、参数区间、证据矩阵 |
| 学术研究与前沿探索 | 论文精读、文献对照、前沿研究、科研写作 | 论文分析、来源比较、研究路线、稿件 |

完整编号、路径和目标见 [模式注册表](skills/physicsbase-helper/references/modes.json)；各模式的适用边界、工作流程、核查、失败处理和例子在其独立 `SKILL.md` 中。总入口位于 [physicsbase-helper](skills/physicsbase-helper/SKILL.md)。

## 学习与研究的使用方法

系统学习时给目标和已学基础，例如“我会数学分析与高等代数，规划广义相对论学习并从第一单元开始”。专题学习会使用 [物理学科目录](skills/physicsbase-helper/references/physics-catalog.md) 建立前置路径，必要时调用数学桥接。习题可直接要求完整解答或逐级提示。

计算时说明模型、单位、初边值和误差目标；结果应附算法、版本、参数、种子、收敛或守恒检查。可视化会区分实际计算曲线与概念示意图。实验数据分析需提供真实数据和校准信息；若使用合成教学数据，必须显著标明。

研究时给精确问题或论文。插件会区分原文、解释、独立推导和推测；对理论结果、数值结果及实验观测分别注明证据等级。最新前沿需要当次检索并保存来源版本与核查日期，不把预印本当成已公认结论。

MathBaseHelper-Pro 是可选的数学工作方法参考。两个插件独立安装、独立版本；本插件不假设能够直接调用另一个插件。

## 结构、验证和扩展

- `plugin.json`：Agent Plugins 1.0 主清单；`.codex-plugin/plugin.json`：兼容旧客户端的同步元数据。
- `skills/physicsbase-helper/`：统一入口、路由、学科目录、V1–V4 验证和证据账本。
- `skills/<mode>/SKILL.md`：24 个独立流程，由 `tools/generate-modes.mjs` 的数据生成。
- `tests/`：结构、负例与物理数值基准。执行 `node tools/generate-modes.mjs`，再执行 `node tests/validate.mjs` 和 `node tests/physics-baselines.mjs`。
- [验证报告](VALIDATION.md)：实际测试状态、覆盖范围和未执行项。

新增领域时按学科目录十字段模板扩展，注明教材层级、来源版本和有效范围。新增模式时在生成脚本中加入完整流程、核查和例子，重新生成注册表及 Skill，更新三处展示文案、README、测试与版本。新增工具后先验证环境和实际后端，不能仅修改能力宣称。新增数据库要记录访问方式、来源和权限；新增实验或可视化模板需有模型、单位、误差及产物核查。详情见 [维护规范](MAINTENANCE.md)。

本仓库不包含个人账户资料、访问令牌或私有研究数据。图标为本项目原创 SVG。
